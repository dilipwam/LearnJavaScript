🚀 Crash Course on Common JavaScript Methods Used in Test Automation

Especially useful for tools like Cypress, Playwright, Selenium (WebDriverJS), and Jest.

🧪 1. Assertions

Used to verify expected results.

// Jest / Mocha / Chai
expect(value).toBe(10);
expect(arr).toContain("apple");
assert.equal(actual, expected);

🔁 2. Looping Constructs

Used for testing data-driven or repetitive steps.

for (let i = 0; i < items.length; i++) {
  console.log(items[i]);
}

items.forEach((item) => {
  expect(item).toBeDefined();
});

🔍 3. Array Methods

map(), filter(), find(), every(), some(), includes()

let names = users.map(u => u.name);
let valid = users.filter(u => u.isActive);
let found = users.find(u => u.id === 1);
expect(names.includes("Alice")).toBe(true);

🔤 4. String Methods

let str = "Automation Test";

expect(str.toLowerCase()).toBe("automation test");
expect(str.includes("Test")).toBe(true);
expect(str.replace("Test", "Script")).toBe("Automation Script");

📦 5. Object Handling

Object.keys(), Object.values(), hasOwnProperty()

let obj = { a: 1, b: 2 };
expect(Object.keys(obj)).toContain("a");
expect(obj.hasOwnProperty("b")).toBe(true);

⌛ 6. Timers & Async Handling

// Wait for element / action
await page.waitForSelector('#submit');
await new Promise(resolve => setTimeout(resolve, 1000));

📄 7. DOM & Browser Actions (with frameworks)

Cypress 
cy.get('#username').type('admin');
cy.contains('Submit').click();
cy.url().should('include', '/dashboard');
Playwright 
await page.fill('#username', 'admin');
await page.click('text=Submit');
await expect(page).toHaveURL(/dashboard/);

📁 8. File & Data Handling

const fs = require('fs');

let raw = fs.readFileSync('data.json');
let data = JSON.parse(raw);

expect(data.users.length).toBeGreaterThan(0);

📐 9. Test Setup & Teardown

beforeAll(() => initBrowser());
afterAll(() => closeBrowser());
beforeEach(() => resetState());
afterEach(() => cleanUp());

🎯 10. Mocking & Spying

jest.spyOn(api, 'getUser').mockReturnValue({ name: 'John' });

📌 11. Common Utility Functions

  • Deep Equality: JSON.stringify(obj1) === JSON.stringify(obj2)
  • Generate Random Data:
const randomStr = Math.random().toString(36).substring(2);
const timestamp = Date.now();

✅ Example Test Snippet (Jest + Puppeteer)

test("login flow", async () => {
  await page.goto("https://example.com/login");
  await page.type("#user", "admin");
  await page.type("#pass", "admin123");
  await page.click("#submit");

  await page.waitForSelector("#dashboard");
  const url = await page.url();
  expect(url).toMatch(/dashboard/);
});

console.log("value:", value);
