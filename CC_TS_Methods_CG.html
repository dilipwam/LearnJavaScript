🚀 Crash Course on Common TypeScript Methods & Concepts Used in Test Automation

Focus: Playwright, Cypress, Jest, WebDriverIO — using TypeScript for type safety and maintainability.

🔰 1. Basic TypeScript Setup for Test Automation

tsconfig.json (simplified)

{
  "compilerOptions": {
    "target": "ES2020",
    "module": "commonjs",
    "strict": true,
    "esModuleInterop": true,
    "types": ["jest", "node", "cypress"]
  }
}

Use .ts instead of .js for your test files.

✅ 2. Typed Test Functions (e.g., Jest / Playwright)

test("check dashboard", async () => {
  const url: string = await page.url();
  expect(url).toContain("dashboard");
});

You get auto-complete & type checking on objects like page, browser, etc., from Playwright’s types.

🔎 3. Typing Web Elements

Playwright:

const button: Locator = page.locator("#submit");
await button.click();

Cypress:

cy.get('input[name="username"]') // auto-completion for commands

🔁 4. Common TS-enhanced JS Methods Used in Tests

Array Methods

const users: string[] = ["Alice", "Bob"];
users.forEach((u: string) => {
  expect(u).toMatch(/\w+/);
});

Object Iteration

type User = { name: string; isAdmin: boolean };
const userObj: Record<string, User> = {
  user1: { name: "Alice", isAdmin: true },
  user2: { name: "Bob", isAdmin: false },
};

Object.entries(userObj).forEach(([key, val]) => {
  expect(typeof val.name).toBe("string");
});

💥 5. Advanced TypeScript in Test Automation

Interfaces for Test Data

interface LoginDetails {
  username: string;
  password: string;
}

const credentials: LoginDetails = {
  username: "admin",
  password: "admin123",
};

Enums for Roles or States

enum Role {
  Admin = "admin",
  User = "user",
}

function loginAs(role: Role) {
  // logic based on role
}

Generics for Reusable Functions

function getElementText<T extends HTMLElement>(selector: string): Promise<string> {
  return document.querySelector(selector)?.textContent ?? "";
}

⌛ 6. Async-Await with Type Inference

const url: string = await page.url(); // ensures return type is string

Incorrect:

const url: string = page.url(); // ❌ Type 'Promise<string>' is not assignable to type 'string'

🧪 7. Type-safe Custom Commands

Cypress Example

declare global {
  namespace Cypress {
    interface Chainable {
      login(username: string, password: string): Chainable<void>;
    }
  }
}

Cypress.Commands.add("login", (username, password) => {
  cy.get("#username").type(username);
  cy.get("#password").type(password);
  cy.get("#login").click();
});

import users from "../fixtures/users.json"; // with typing

const firstUser: User = users[0];

🧪 10. Real Test Example (Playwright + TypeScript)

import { test, expect, Page } from '@playwright/test';

test('valid login', async ({ page }: { page: Page }) => {
  await page.goto("https://example.com/login");
  await page.fill("#username", "admin");
  await page.fill("#password", "admin123");
  await page.click("text=Login");

  const url: string = await page.url();
  expect(url).toContain("/dashboard");
});

📚 BONUS: Utility Functions in TypeScript for Test Automation

export function generateRandomEmail(): string {
  return `user_${Math.random().toString(36).substring(2)}@mail.com`;
}

export function delay(ms: number): Promise<void> {
  return new Promise(resolve => setTimeout(resolve, ms));
}

Concept Why It Matters in Testing

Enum Role/status flags
Generics Flexible utilities
readonly, Partial, Pick, Omit Fine-tune types for mock data
