🚀 TypeScript Crash Course

What is TypeScript?

TypeScript is a superset of JavaScript that adds static typing and type checking. It compiles to plain JavaScript and helps catch bugs at compile-time instead of run-time.

1. ✅ Basic Types

let id: number = 1;
let name: string = "John";
let isActive: boolean = true;
let anyValue: any = "Could be anything";
let data: unknown = 42;

Arrays & Tuples

let numbers: number[] = [1, 2, 3];
let user: [string, number] = ["Alice", 25]; // Tuple

Enums

enum Direction {
  Up,
  Down,
  Left,
  Right,
}
let dir: Direction = Direction.Up;

2. 🔤 Type Inference

TypeScript can infer types:

let greeting = "Hello"; // inferred as string

3. 🏗️ Functions

function add(x: number, y: number): number {
  return x + y;
}

Optional & Default Parameters

function log(msg: string, user?: string) {
  console.log(msg, user ?? "Anonymous");
}

4. 🧱 Interfaces & Types

Interface

interface User {
  name: string;
  age: number;
  isAdmin?: boolean;
}

Type Alias

type ID = number | string;
type UserStatus = "active" | "inactive";

5. 🏷️ Type Unions & Intersections

let value: string | number = "Hello"; // Union

type Admin = { role: string };
type Person = { name: string };
type AdminPerson = Admin & Person; // Intersection

6. 👷 Classes

class Animal {
  constructor(public name: string) {}
  speak(): void {
    console.log(`${this.name} makes a noise.`);
  }
}

class Dog extends Animal {
  speak(): void {
    console.log(`${this.name} barks.`);
  }
}

7. 🔐 Access Modifiers

class Example {
  public name: string;
  private secret: string;
  protected age: number;

  constructor() {
    this.name = "Public";
    this.secret = "Private";
    this.age = 30;
  }
}

8. 🧬 Generics

function identity<T>(value: T): T {
  return value;
}

let output = identity<string>("Hello");

9. 📋 Type Assertions

let someValue: unknown = "I am a string";
let strLength = (someValue as string).length;

10. 🌐 Modules & Namespaces

Export / Import (ES Modules)

// user.ts
export interface User {
  name: string;
}

// main.ts
import { User } from "./user";

11. 🔁 Utility Types

  • Partial<T> – all properties optional
  • Readonly<T> – all properties read-only
  • Pick<T, K> – pick specific keys
  • Omit<T, K> – omit specific keys
  • Record<K, T> – construct type with set of properties
type User = { name: string; age: number };
type ReadonlyUser = Readonly<User>;
type PartialUser = Partial<User>;

12. 🧪 Type Guards

function isString(value: unknown): value is string {
  return typeof value === "string";
}

13. 🧯 Error Handling

function fail(msg: string): never {
  throw new Error(msg);
}

14. ⛓️ Type Narrowing

function print(val: string | number) {
  if (typeof val === "string") {
    console.log(val.toUpperCase());
  } else {
    console.log(val.toFixed(2));
  }
}

15. 🧩 Declaration Files

Used to provide types for JS libraries.

// @types/lodash or declare module 'module-name'

16. 📦 tsconfig.json

Controls how TypeScript behaves.

{
  "compilerOptions": {
    "target": "ES6",
    "module": "commonjs",
    "strict": true,
    "esModuleInterop": true
  }
}

🧠 Bonus: Advanced Topics

  • Mapped Types – e.g., keyof, in
  • Conditional Types – T extends U ? X : Y
  • Infer keyword – for inferring types inside generics
  • Discriminated Unions – using a common kind property

📚 Common Tools & Ecosystem

  • TypeScript Compiler (tsc)
  • ESLint + Prettier for linting/formatting
  • ts-node: run .ts files directly
  • Webpack / Vite for bundling
