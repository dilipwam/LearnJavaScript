JavaScript Crash Course

1. Introduction to JavaScript

JavaScript is a lightweight, interpreted programming language primarily used for creating dynamic web content. It is a core technology of the World Wide Web, alongside HTML and CSS.

2. Basic Syntax

  • Variables: Used to store data values. Declared using var, let, or const.
let name = "John";
const age = 30;
var isStudent = true;
  • Data Types: Includes numbers, strings, booleans, objects, arrays, null, and undefined.
let number = 42;
let text = "Hello, World!";
let isTrue = false;
let person = { firstName: "John", lastName: "Doe" };
let colors = ["red", "green", "blue"];

3. Operators

  • Arithmetic Operators: +, -, *, /, %
  • Comparison Operators: ==, ===, !=, !==, >, <, >=, <=
  • Logical Operators: &&, ||, !

4. Control Structures

  • Conditional Statements: if, else if, else, switch
if (age > 18) {
  console.log("Adult");
} else {
  console.log("Minor");
}
  • Loops: for, while, do...while, for...in, for...of
for (let i = 0; i < 5; i++) {
  console.log(i);
}

5. Functions

Functions are blocks of code designed to perform a particular task.

function greet(name) {
  return `Hello, ${name}!`;
}
console.log(greet("Alice"));

6. Objects and Arrays

  • Objects: Collections of key-value pairs.
let car = {
  make: "Toyota",
  model: "Corolla",
  year: 2020
};
  • Arrays: Ordered lists of values.
let fruits = ["apple", "banana", "cherry"];

7. Events

JavaScript can respond to user actions like clicks, key presses, and mouse movements.

document.getElementById("myButton").addEventListener("click", function() {
  alert("Button clicked!");
});

8. Asynchronous JavaScript

  • Callbacks: Functions passed as arguments to other functions.
function fetchData(callback) {
  setTimeout(() => {
    callback("Data received");
  }, 1000);
}
fetchData((message) => {
  console.log(message);
});
  • Promises: Objects representing the eventual completion or failure of an asynchronous operation.
let promise = new Promise((resolve, reject) => {
  let success = true;
  if (success) {
    resolve("Operation successful");
  } else {
    reject("Operation failed");
  }
});
promise.then((message) => {
  console.log(message);
}).catch((error) => {
  console.error(error);
});
  • Async/Await: Syntactic sugar for working with promises.
async function fetchData() {
  let response = await fetch("https://api.example.com/data");
  let data = await response.json();
  console.log(data);
}
fetchData();

9. DOM Manipulation

JavaScript can interact with and manipulate the Document Object Model (DOM) of a webpage.

document.getElementById("myElement").innerHTML = "New content";

10. Error Handling

  • Try/Catch: Handling exceptions in code.
try {
  let result = riskyOperation();
} catch (error) {
  console.error("An error occurred:", error);
}
