🚀 TypeScript Crash Course

🟦 1. What is TypeScript?

TypeScript (TS) is a superset of JavaScript that adds static typing, interfaces, and advanced tooling. It compiles to plain JavaScript.

🧠 2. Key Concepts & Terminologies

🔹 Types

let age: number = 25;
let name: string = "Alice";
let isActive: boolean = true;

🔹 Type Inference

let city = "Delhi"; // inferred as string

🔹 Interfaces

interface User {
  name: string;
  age: number;
}

const user: User = { name: "Bob", age: 30 };

🔹 Functions

function greet(name: string): string {
  return `Hello, ${name}`;
}

🔹 Optional & Default Parameters

function log(message: string, user?: string) {
  console.log(message, user);
}

🔹 Arrays & Tuples

let numbers: number[] = [1, 2, 3];
let tuple: [string, number] = ["age", 30];

🔹 Union & Literal Types

let value: string | number;
value = "hello";
value = 42;

type Direction = "left" | "right";
let move: Direction = "left";

🔹 Enums

enum Status {
  Success,
  Error,
  Pending
}
let s: Status = Status.Success;

🔹 Type Aliases

type ID = string | number;
let userId: ID = 123;

🔹 Generics

function identity<T>(arg: T): T {
  return arg;
}
let output = identity<string>("test");

🔹 Classes

class Animal {
  constructor(public name: string) {}
  speak() {
    console.log(`${this.name} makes a sound.`);
  }
}

🔹 Access Modifiers

  • public (default): accessible everywhere
  • private: accessible only within the class
  • protected: accessible in class and subclasses

🔹 Type Assertions

let someValue: any = "hello";
let strLength: number = (someValue as string).length;

🔹 Modules

// file: math.ts
export function add(a: number, b: number): number {
  return a + b;
}

// file: app.ts
import { add } from "./math";

🔹 Utility Types

  • Partial<T>, Readonly<T>, Record<K, T>, Pick<T, K>, Omit<T, K>
interface Todo { title: string; done: boolean; }
let t: Partial<Todo> = { title: "Learn TS" };

🧩 TypeScript In Practice

  • Used for: Large-scale JS apps, safer code, better tooling
  • Integrates with React, Node.js, Angular, Vue
  • Compiles to JavaScript (tsc command)
  • Configuration: tsconfig.json
