🚀 JavaScript Crash Course

🟨 1. What is JavaScript?

JavaScript (JS) is a high-level, interpreted scripting language used to create dynamic and interactive web content.

🧠 2. Key Concepts & Terminologies

🔹 Variables

Used to store data values.

let name = "John"; // ES6 preferred
const age = 30;    // Constant
var city = "Delhi"; // Old (avoid)

🔹 Data Types

  • Primitive: String, Number, Boolean, null, undefined, Symbol, BigInt
  • Non-Primitive: Object, Array, Function
let x = 10;           // Number
let name = "Alice";   // String
let isCool = true;    // Boolean
let list = [1, 2, 3]; // Array
let person = {name: "Bob", age: 25}; // Object

🔹 Operators

  • Arithmetic: +, -, *, /, %
  • Comparison: ==, ===, !=, !==, <, >
  • Logical: &&, ||, !
  • Assignment: =, +=, -=, etc.

🔹 Conditionals

if (age > 18) {
  console.log("Adult");
} else {
  console.log("Minor");
}

🔹 Loops

for (let i = 0; i < 5; i++) {
  console.log(i);
}

while (x < 5) {
  x++;
}

🔹 Functions

Reusable blocks of code.

function greet(name) {
  return "Hello " + name;
}

➡️ Arrow Function (ES6):

const greet = (name) => `Hello ${name}`;

🔹 Arrays

let fruits = ["apple", "banana"];
fruits.push("mango");       // Add
let first = fruits[0];      // Access

➡️ Looping over array:

fruits.forEach(f => console.log(f));

🔹 Objects

Key-value pairs

let user = {
  name: "Sara",
  age: 22,
  greet: function() {
    console.log("Hi!");
  }
};

🔹 DOM Manipulation

JS can manipulate HTML via the DOM.

document.getElementById("myBtn").innerText = "Clicked!";

🔹 Events

Reacting to user actions

document.querySelector("button").addEventListener("click", () => {
  alert("Clicked!");
});

🔹 Scope

  • Global: Outside all blocks
  • Local: Inside a function/block
  • Block Scoped: let, const

🔹 Hoisting

Variables and functions are moved to the top of their scope before execution.

console.log(a); // undefined
var a = 10;

🔹 Closures

Functions remember the scope in which they were created.

function outer() {
  let count = 0;
  return function inner() {
    count++;
    console.log(count);
  };
}
const inc = outer();
inc(); // 1
inc(); // 2

🔹 Callbacks & Promises

For async operations.

// Callback
function loadData(cb) {
  setTimeout(() => cb("Data loaded"), 1000);
}

// Promise
let promise = new Promise((resolve, reject) => {
  resolve("Done!");
});

promise.then(res => console.log(res));

🔹 Async/Await

Syntactic sugar over Promises

async function fetchData() {
  let result = await fetch("https://api.com");
  let data = await result.json();
}

🔹 Error Handling

try {
  // risky code
} catch (err) {
  console.log("Error:", err);
}

🔹 ES6+ Features

  • let, const
  • Arrow functions
  • Template literals: `Hello ${name}`
  • Destructuring
  • Spread/rest: ...
  • Default params
  • Modules: import, export

🔹 Classes (OOP)

class Person {
  constructor(name) {
    this.name = name;
  }
  greet() {
    return `Hi, I’m ${this.name}`;
  }
}

🧩 JavaScript In Practice

  • Used for: Web apps, APIs (Node.js), mobile apps (React Native), games, automation
  • Runs in browser or server (Node.js)
  • JS Frameworks: React, Angular, Vue
  • Linting: ESLint, Prettier
  • Package Manager: npm, yarn

✅ Must-Know for Interviews

  • Variable scope
  • Hoisting
  • Event loop
  • Promises vs Callbacks
  • this keyword
  • Array methods: map, filter, reduce
  • Closure
  • Debounce/throttle
