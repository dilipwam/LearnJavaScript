Common JavaScript Methods

Method Description Example
document.querySelector() Selects the first element that matches a specified CSS selector. 
const element = document.querySelector('.class-name');
document.querySelectorAll() Selects all elements that match a specified CSS selector. 
const elements = document.querySelectorAll('.class-name');
element.click() Simulates a mouse click on an element. 
element.click();
element.value Gets or sets the value of an input element. 
element.value = 'new value';
element.innerText Gets or sets the text content of an element. 
element.innerText = 'new text';
element.innerHTML Gets or sets the HTML content of an element. 
element.innerHTML = '<strong>new HTML</strong>';
element.addEventListener() Adds an event listener to an element. 
element.addEventListener('click', function() {
    console.log('Element clicked');
});
setTimeout() Executes a function after a specified delay. 
setTimeout(function() {
    console.log('Executed after 2 seconds');
}, 2000);
setInterval() Executes a function repeatedly at specified intervals. 
setInterval(function() {
    console.log('Executed every 2 seconds');
}, 2000);
fetch() Makes an HTTP request and returns a promise. 
fetch('https://api.example.com/data')
    .then(response => response.json())
    .then(data => console.log(data));

JavaScript Testing Frameworks

Here are some popular JavaScript testing frameworks used in test automation:

  • Jest: A delightful JavaScript testing framework with a focus on simplicity.
  • Mocha: A flexible JavaScript test framework for Node.js.
  • Jasmine: A behavior-driven development framework for testing JavaScript code.
  • Cypress: A fast, easy, and reliable testing framework for anything that runs in a browser.
  • Playwright: A framework for end-to-end testing of web applications.

Example Test Script

Here's an example of a simple test script using Jest:

const { test, expect } = require('@jest/globals');

test('adds 1 + 2 to equal 3', () => {
    expect(1 + 2).toBe(3);
});
